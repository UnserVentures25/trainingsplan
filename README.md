# Trainingsplan

Dreitägiger Trainingsplan mit dem eigenen Körpergewicht, ohne Geräte, für den Einstieg.
Dazu ein Ernährungsplan mit konkreten Mengen sowie Do's und Don'ts.

**Online lesen:** https://unserventures25.github.io/trainingsplan/
**Druckversion (PDF):** [trainingsplan-druckversion.pdf](trainingsplan-druckversion.pdf)

Die Seite ist eine einzelne HTML-Datei mit eingebetteten Schriften — sie funktioniert
offline, auf dem Handy und lässt sich direkt aus dem Browser ausdrucken.

Kein medizinischer Rat. Vor dem Trainingseinstieg ärztlich abklären lassen.
